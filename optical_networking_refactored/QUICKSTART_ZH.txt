整理版代码：使用说明

1. 解压整个 ZIP，用 VS Code 打开里面的 optical_networking_refactored 文件夹。
   三个核心 .py 文件需要放在同一个目录。

2. 在该文件夹的终端运行：

   python -m pip install -r requirements.txt
   python run_experiments.py

   如果当前 Python 已有这些依赖，可以跳过安装。
   默认只运行第 25 步的距离实验；也可以在 VS Code 中直接运行这个入口文件。
   physical_model.py 和 network_model.py 是供导入的模块，单独运行它们没有输出。

3. 切换实验：

   python run_experiments.py --experiment baseline
   python run_experiments.py --experiment physical
   python run_experiments.py --experiment allocation
   python run_experiments.py --experiment power
   python run_experiments.py --experiment margin
   python run_experiments.py --experiment max-margin
   python run_experiments.py --experiment distance

   physical 对应 SNR-P、C-P、C-L；power/margin/max-margin/distance
   分别对应第 22/23/24/25 步。allocation 对比顺序分配、穷举和 ILP。

4. 运行全部实验并只保存图片：

   python run_experiments.py --experiment all --no-show

   新结果默认保存在 results 文件夹，包括 PNG 和数值 JSON。
   example_results 文件夹是本次已经验证过的参考结果。

5. 重跑回归检查：

   python -m unittest -v test_regression

   正常结束应显示 Ran 9 tests 和 OK。

6. 修改位置：
   物理参数：physical_model.py 中的 PhysicalConfig。
   拓扑、空闲波长、请求：network_model.py 中的 toy_case。
   扫描范围：run_experiments.py 中对应的 experiment_* 函数。

本次保持原公式和基线结果，并把功率、请求和资源状态改为显式传参。
每条链路必须包含整数个完整跨；默认每跨 80 km，不再静默截断跨数。
已在 Linux Python 3.12 验证，尚未直接在你的 Windows Python 3.13 上运行。
详细模型假设与英文说明见 README.md。
